# Security policy

Do not disclose credentials, private keys, access tokens, unpublished personal data or an exploitable vulnerability in a public issue or discussion.

For a vulnerability affecting this repository, use GitHub's private security-advisory channel:

https://github.com/nobelJackal/NOMOS-GEO-QA/security/advisories/new

For integrity concerns about a published file, include the affected path, version, observed SHA-256 value and the corresponding locale manifest. Non-sensitive editorial or metadata corrections may be reported through the repository's public issue tracker.

NobleJackal cannot promise a response or remediation deadline, but reports will be assessed in proportion to their reproducibility and impact.
