# NOMOS GEO-QA v0.3.1

**Canonical Question Registry — six-language founder edition**

[![English edition DOI](https://zenodo.org/badge/DOI/10.5281/zenodo.22108413.svg)](https://doi.org/10.5281/zenodo.22108413) [![ORCID](https://img.shields.io/badge/ORCID-0009--0000--2277--9009-A6CE39?logo=orcid)](https://orcid.org/0009-0000-2277-9009) [![Rights](https://img.shields.io/badge/rights-all%20rights%20reserved-lightgrey)](RIGHTS.md)

NOMOS GEO-QA is a founder-proposed representation-governance and audit framework developed by NobleJackal and authored by Kaan Muraz. Version 0.3.1 contains 69 canonical questions, 98 controlled terms and a 64-source research, standards and provider-documentation index in English, Turkish, German, Spanish, Russian and Arabic.

> **Status boundary:** Publication does not establish official, global or independently adopted industry-standard status. This work is not an accreditation, certification or independent validation, and it does not guarantee rankings, visibility, downloads or citations.

## Machine-readable publication

Each locale directory under **data/** contains:

- **registry.json** and **registry.jsonl** — the 69 canonical records;
- **glossary.json** — 98 controlled terms;
- **sources.json** — the 64-source index;
- **manifest.json** — version, canonical routes, rights boundary and SHA-256 integrity ledger;
- **citation.json** — locale-specific citation metadata.

The shared versioned schema is available at **schema/nomos-geo-qa-public-core-v0.3.1.json**. The same package, including the six PDFs, is mirrored at [Hugging Face](https://huggingface.co/datasets/NobleJackal/NOMOS-GEO-QA).
